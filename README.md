# Skin Lesion Analysis with Machine Learning

Projeto de visão computacional aplicado à análise de lesões cutâneas, desenvolvido como estudo prático de aprendizado de máquina e aprendizado profundo.

## 📌 Objetivo
Investigar métodos clássicos e baseados em deep learning para segmentação de lesões dermatológicas e classificação de malignidade.

## 🗂️ Dataset
- ISIC Archive
- Imagens dermatoscópicas com máscaras de segmentação e rótulos clínicos

> ⚠️ As imagens não estão incluídas neste repositório por questões de tamanho e licença.

## 🧠 Metodologia
1. Pré-processamento com remoção de pelos
2. Segmentação clássica via K-means (baseline)
3. Segmentação profunda via U-Net (prova de conceito)
4. Avaliação qualitativa e quantitativa
5. Classificação baseada no método ABCD (em desenvolvimento)

## 📊 Resultados Parciais
- O pré-processamento reduziu ruídos lineares
- O K-means apresentou desempenho variável
- A U-Net demonstrou segmentações mais contínuas e robustas

## 🚧 Próximos Passos
- Implementação computacional do método ABCD
- Classificação benigno vs maligno
- Avaliação quantitativa da classificação

## 🛠️ Tecnologias
